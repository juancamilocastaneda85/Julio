# Fp Icon

App para cambiar el icono de huella de la pantalla de bloqueo (S20 FE, VoltageOS, Android 16).

Requisitos en el telefono: root, y en Termux ya instalados `imagemagick`, `potrace`, `apksigner`,
`~/framework-res.apk` y `~/rro.keystore` (los que creamos antes).

La compilacion la hace GitHub Actions: pestana **Actions > Build APK > FpIconApp** para descargar el APK.
